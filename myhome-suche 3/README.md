# My Home is my Home — Immobilien Suchassistent

## Setup

1. Repository auf GitHub pushen
2. Auf vercel.com einloggen → "Add New Project" → GitHub Repo wählen
3. Environment Variable setzen: `ANTHROPIC_API_KEY` = dein Anthropic API Key
4. Deploy klicken → fertig

## Lokale Entwicklung

```bash
npm install
npm run dev
```

Dann http://localhost:3000 öffnen.
